# Chiikawa 风格动画制作 —— 路线全景与实操教程

> 调研日期：2026-09-14
> 目标：搞清楚抖音上那些 Chiikawa 动画到底是怎么做的，给出可照抄的路线。

---

## 0. 先搞懂一个概念：三渲二

你在抖音看到的 Chiikawa 动画，**绝大多数是「三渲二」**（也叫 NPR / 卡通渲染 / Cel Shading）。

| | 说明 |
|---|---|
| **模型** | 真的 3D 模型，建了模、绑了骨、K 了帧 |
| **渲染** | 输出成 2D 手绘动漫的样子 |
| **为什么这么做** | 兼具 2D 的画风 + 3D 的可控性（自由转视角、动作丝滑、能复用） |

**核心原理一句话**：把连续平滑的光影过渡，**量化成硬邦邦的色块**。

真实世界里光照射到球体上，明暗是渐变的；三渲二把它压成"亮面一块、暗面一块"，边界清晰。这就是为什么动漫看起来"平"。

理解这点，后面所有工具就都好懂了 —— 软件都在做 3D，差别只在**渲染成什么风格**。

## 1. 五条技术路线对比

| 路线 | 工具 | 难度 | 适合谁 | 抖音热度 |
|---|---|---|---|---|
| ① **主流 · 三渲二** | Blender + NPR 材质 | 中 | 绝大多数人 | ★★★★★ |
| ② **电影级** | Unreal Engine 5 + MooaToon | 高 | 进阶 / 追求画质 | ★★★★ |
| ③ **老牌商业** | C4D + Arnold / Maya | 中高 | 有 3D 基础 | ★★★ |
| ④ **纯 AI 出片** | LMArena / 即梦 / 可灵 | 低 | 不想学软件的 | ★★★ 增长快 |
| ⑤ **手办 / 实物向** | Blender 或直接 LMArena | 低 | 只要能发圈的图 | ★★★★ |

### 结论先行

**Blender 是绝对主流**。抖音、B站上 90% 的 Chiikawa 教程都是它，原因：

1. **免费**（开源，不用买 license）
2. **轻量**（普通笔记本能跑）
3. **NPR 三渲二生态成熟**（教程、插件、材质预设一大堆）
4. **现成模型资源多** —— 网上有下载好的 Chiikawa 模型和绑定文件，可以跳过建模和绑骨

## 2. 【路线①】Blender 三渲二 —— 完整实操教程

这是推荐入口。整个流程五步：

```
建模 → 绑定骨骼 → K帧动画 → 三渲二材质 → 渲染出片
 ①        ②          ③           ④          ⑤
```

> **省力技巧**：Chiikawa 造型极简（圆头 + 豆豆眼），建模是最简单的部分。
> 更省力的做法是**直接下载现成的 Chiikawa 3D 模型 + 绑定文件**，
> 跳过 ①② 两步，只学 ④ + ③。学习量直接砍一半。

### 步骤 ④：三渲二材质（灵魂步骤）

这是整个流程的核心。下面是**最简可行的卡通着色节点搭建**，5 个节点搞定。

#### 节点连接方式

```
Diffuse BSDF  →  Shader to RGB  →  ColorRamp  →  Material Output
  (漫射BSDF)      (着色器转RGB)     (颜色渐变)      (材质输出)
```

**注意**：`Shader to RGB` 节点**只在 Eevee 渲染引擎下可用**，Cycles 不支持。所以做三渲二要用 **Eevee**。

#### 具体参数

| 节点 | 设置 |
|---|---|
| **Diffuse BSDF** | 替换掉默认的 Principled BSDF（原理化BSDF） |
| **Shader to RGB** | 把光照计算的结果转换成颜色数据 |
| **ColorRamp** | ⚠️ **插值类型改成「常值」（Constant）**，不是默认的线性 |
| **ColorRamp 滑块** | 右端滑块拖到中间 **0.5** 位置 |

**原理**：ColorRamp 左右两端分别是两个颜色 ——
- **右侧** = 受光面颜色（亮部）
- **左侧** = 阴影面颜色（暗部）

因为插值改成了 Constant，两个颜色之间是**硬切换**，于是就有了动漫那种色块分明的效果。

#### 多材质配合

角色的不同部位要**分开建材质**（脸、眼睛、瞳孔、鼻子、嘴），
每个材质用**同一套节点结构**，但在 ColorRamp 里给**不同的颜色值**。
这样眼睛是纯黑、脸是肤色，各自独立分色。

#### 描边（轮廓线）

三渲二少了黑边就没味道。主流做法两种：

| 方法 | 做法 | 优缺点 |
|---|---|---|
| **实体化修改器法**（推荐） | 加 Solidify 修改器，翻转法线 + 背面剔除，用黑色材质 | 可控、能调粗细、支持局部描边 |
| **Freestyle** | Blender 内置描边渲染，勾选即可 | 简单但慢、不易控 |

实体化法要点的：复制一份模型 → 沿法线外扩一点 → 材质设成纯黑 → 开 Backface Culling（只显示背面）→ 于是从外面看就只剩一圈黑边。

### 步骤 ⑤：渲染设置

| 项 | 建议 |
|---|---|
| **引擎** | Eevee（三渲二必须；实时快，且支持 Shader to RGB） |
| **分辨率** | 抖音竖屏用 1080×1920 |
| **帧率** | 24 或 30 fps |
| **输出** | 先出 PNG 序列帧，再用剪辑软件合成（比直接出 MP4 稳） |

### 完整学习路径建议

1. 先看一条**入门总览**，建立流程认知
2. 单独攻克**三渲二材质**（这是最卡人的一步）
3. 学**绑骨 + K 帧**（让角色动起来）
4. 最后学**渲染输出 + 剪辑**

## 3. 【路线②】UE5 + MooaToon —— 电影级画质

虚幻引擎本来是做游戏的，但社区做了个开源插件 **MooaToon**，专攻**电影级卡通渲染**。

- **GitHub**：https://github.com/JasonMa0012/MooaToon
- **定位**：The Ultimate Solution for Cinematic Toon Rendering in UE5

**那些光影高级、有体积光、画面有"电影质感"的 Chiikawa，很多是这条路。**

| | 评价 |
|---|---|
| 优势 | 画质天花板，光影效果远超 Blender |
| 代价 | 学习曲线陡、吃显卡（建议 3060 以上）、项目文件巨大、启动慢 |
| 适合 | 有 3D 基础、追求画面质感、电脑配置好 |

---

## 4. 【路线③】C4D + Arnold / Maya

商业动画公司的传统路线（C4D 配 Arnold 渲染器做美式卡通三渲二）。

- **Maya**：老牌工业标准，大厂动画用得多
- **C4D + Arnold**：动态图形（Motion Graphics）强项，广告片常用

**对个人创作者偏重**，Chiikawa 这种小短片不太需要。学了不亏，但性价比不如 Blender。

---

## 5. 【路线④】纯 AI 出片

不建模、不学软件，AI 出图 + AI 出视频（就是你最早发的那条抖音）。

**优点**：零门槛，半小时能出片
**缺点**：
- 角色一致性难保证（换个镜头角色就变形）
- 动作不可控，只能抽卡
- 做不了复杂叙事

**流程**：找参考图（小红书）→ LMArena 出 3D 风格图 → 即梦/可灵加动效

> ⚠️ **时效提醒**：LMArena 在 2026-04 下调了 Image Arena 限流，
> 视频里"无限免费抽卡"的说法已失效。达上限会 suspend 15 分钟~1 小时。

---

## 6. 怎么选：决策表

| 你的情况 | 推荐 |
|---|---|
| 完全零基础、想快速出片 | ④ 纯 AI，先用即梦/可灵试水 |
| 想认真做、能投入时间学 | ① **Blender 三渲二**（教程最多、资源最全） |
| 有 3D 基础、追求画面质感 | ② UE5 + MooaToon |
| 只想做手办图发朋友圈 | ⑤ Blender 或直接 LMArena |

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "Chiikawa 动画是 2D 手绘的" | 主流是 3D 模型 + 三渲二渲染 |
| "要用很贵的软件" | Blender 免费，功能足够做抖音爆款 |
| "必须先学建模" | 可以下载现成模型，跳过建模和绑骨 |
| "三渲二很难" | 最简版只要 5 个节点，一小时能学会 |
