## 三、一手做法：Blender 建模流程（假如我是一个兔，1.4万赞）

来源：视频转文字稿 `txt/7461848502918761778.txt`

### 核心思路

**用参考图垫底，照着描。**

```
导入参考图 → 立方体+细分 → 拖成大致形状 → 环切加线精修 → 上材质 → 合并 → 雕刻修形
```

### 逐部件做法

| 部件 | 做法 |
|---|---|
| **参考图** | `Shift+A` 新建图像参考，导入小八图，菜单栏把「深度/边」设为**前**，降低不透明度 |
| **脸** | 新建**立方体** → 添加**表面细分**（层级3）→ `S` 放大 → 形变工具把脸拉宽 → 平滑着色 → 侧视图压扁 |
| **身体** | `Shift+D` 复制脸 → `Z` 往下挪 → 缩小 |
| **耳朵** | 立方体 + 细分 → 编辑模式 → `Ctrl+R` **环切** → 照参考图塑形 → 压扁。做「猫耳朵尖朝前」时框选 4 个点往前移 |
| **手** | 立方体 + 细分 → 照图调大小 → `Ctrl+R` 加环切。**手不对称所以不做镜像**，直接复制旋转 180° |
| **脚** | 复制手 → 移到脚的位置 |
| **尾巴** | **路径曲线** → 倒角深度 → `G` 移动各点对齐图 → 转网格 → `Alt` 选边 `F` 封盖 → `Ctrl+B` 倒角 → 雕刻模式修形 |
| **五官** | 新建**平面** → 旋转 90° → 压扁当眼睛。**眉毛/眼睛/嘴/下巴黑点都是复制同一个平面改出来的** |
| **腮红** | 复制平面 → 改大小 → 加细分 |

### 材质做法（关键差异）

- 身体：新建材质，基础色**亮度直接拉满**（小八是最白的）
- 尾巴：用**吸管**吸参考图颜色
- 五官：大部分统一黑色 → 全选后 `Ctrl+L` **关联材质**
- **材质用「自发光」（Emission）** ← 这一点很重要

### 收尾

`Ctrl+A` 应用变换 → `Ctrl+J` 合并耳朵/头/身体 → 进**雕刻模式**用「抓起」「弹性变形」笔刷融合接缝（`F` 调笔刷大小）

## 四、一手做法：Blender 动画流程（舞蹈教程）

来源：视频转文字稿 `txt/7465670258221763878.txt`

### 绑定用 Rigify（不是我用的手搓骨骼）

```
偏好设置勾选 Rigify 插件 → Shift+A 新建「基本人体骨架」→
编辑模式调骨骼 → 生成控制器 → Ctrl+P 附带自动权重
```

要点：
- 调整脊椎骨架时必须**选骨点**移动，脱离的话不能生成骨架
- 头部**只保留一根骨骼**（头大没脖子）
- 腮红不在自动权重里 → 用**物体约束 → 子集（Child Of）**绑到头部骨骼，记得勾**反向**

### 动画

- 姿态模式 → 只留 **IK**，其他关掉
- `A` 全选 → `I` 键 K「位置/旋转/缩放」
- 关键帧间隔：第 1 针 → 第 50 针
- **开自动插针**，移动时自动打关键帧，不用手动按 `I`

### 三渲二材质（他们怎么做的）

> 「先加一个描边，然后添加一个实体化修改器，其他都可以复制，**记得别忘记把材质都改成自发光**」

拆解：
1. **描边** + **实体化（Solidify）修改器** ← 和我做的一致
2. **材质改成自发光** ← 用 Emission 输出

### 其他技巧

- 尾巴用**蜡笔画笔**（Grease Pencil）+ `Ctrl+P` 绑到尾巴骨骼
- 舞台上直接用**图片平面**当背景
- 相机用**正焦**（正交），`N` 键锁定后调位置

## 五、我的做法 vs 抖音做法：对比

| 环节 | 我做的 | 抖音做法 | 谁更优 |
|---|---|---|---|
| 建模方式 | **程序化生成**（Python 脚本） | **手动照着参考图捏** | 各有所长 |
| 基础形体 | UV 球 | **立方体 + 表面细分** | 立方体起形更灵活，球体更快 |
| 造型依据 | 凭参数估计 | **导入参考图垫底描** | **抖音更准** |
| 三渲二 | Geometry Normal + 点乘 | 自发光材质 | 殊途同归 |
| 材质输出 | Emission | Emission | 一致 |
| 描边 | Solidify + 翻转法线 | Solidify | 一致 |
| 骨骼 | 手搓 4 根 | **Rigify 插件 + IK** | 动作复杂时 Rigify 强 |
| 绑定 | 按材质槽刚性分配 | Ctrl+P 自动权重 + 子集约束 | 我的更干净，他们的更快 |
| 动画 | 脚本 K 帧 | 姿态模式手动 K + 自动插针 | 手动更适合表演 |
| 背景 | 世界纯色 | **图片平面当舞台** | 抖音更有场景感 |

### 核心收获

1. **他们垫参考图描，我是凭参数算** → 这是最大的方法论差异。
   垫图建模能保证「像」，我的程序化建模胜在可复现和批量。
2. **材质一定要用自发光（Emission）** → 这点我踩坑后碰巧走对了（绕开 Shader to RGB 时用了 Emission）。
3. **Rigify + IK** 是做复杂动作的标准姿势，我手搓骨骼只适合简单动画。
4. **腮红等小部件用 Child Of 约束**而不是权重绑定 → 比我拆网格的做法更省事。
