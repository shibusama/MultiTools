## 制作流程

```
建模 → 三渲二材质 → 描边 → 骨骼 → 刚性绑定 → K帧动画 → 渲染 → 合成
```

### 各环节要点

| 环节 | 做法 |
|---|---|
| **建模** | 程序化生成 8 个部件：身体（扁球）、双耳、双眼、嘴、双腮红 |
| **三渲二材质** | Geometry Normal + 向量点乘算 Lambert → ColorRamp 量化成硬边色块 |
| **描边** | Solidify 外扩 + 翻转法线 + 背面剔除，**只作用于身体和耳朵** |
| **骨骼** | Root / Body / Ear_L / Ear_R，共 4 根 |
| **绑定** | 按材质槽刚性分配权重，每顶点 100% 归属单一骨骼 |
| **动画** | 72 帧：Root 上下浮动（呼吸）+ 双耳交替摇摆 |
| **渲染** | Eevee，透明背景 PNG 序列 |
| **合成** | ffmpeg 白底叠加 |

## 三个技术坑（均已解决）

### 坑 1：Blender 5.2 的 `Shader to RGB` 节点失效

**现象**：网上所有三渲二教程都用 `Diffuse BSDF → Shader to RGB → ColorRamp`，
但在 Blender 5.2 下**节点还存在、接口正常，输出却恒为 0**，
导致 ColorRamp 永远只走左侧（全图判为阴影）。

**定位方法**：A/B 测试 —— 把阈值设成 0.01 和 0.99 分别渲染，
**两次结果像素完全相同**，证明 ColorRamp 的输入根本没变。

**解决**：绕开该节点，用 `Geometry Normal` + 向量点乘手工计算光照：

```
Geometry.Normal --\
                   --> Vector Math(DOT) --> Math(MAD映射到0-1) --> Clamp --> ColorRamp --> Emission
光源方向向量    --/
```

数学透明、完全可控，且不依赖任何可能失效的节点。

### 坑 2：描边糊住五官

**现象**：对整个合并网格加 Solidify 外扩，眼睛和腮红也被包了一层黑壳，
视觉上是"眼睛被切开、腮红变月牙"。

**解决**：拆成两个网格对象，绑定到同一套骨骼：
- `Chiikawa_Body` —— 身体 + 耳朵，**带描边**
- `Chiikawa_Face` —— 眼睛 + 嘴 + 腮红，**不带描边**

### 坑 3：自动权重撕裂模型

**现象**：`ARMATURE_AUTO` 自动权重会把靠近的小部件权重混合，
眼睛被拉成椭圆。

**解决**：改**刚性绑定** —— 遍历多边形的材质索引，
按材质名映射到骨骼，每个顶点 100% 归属单一骨骼，无混合。
校验：权重异常顶点数 = 0。
